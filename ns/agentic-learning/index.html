Agentic Learning Vocabulary

This small vocabulary extends the W3C Web Annotation Data Model with presentation-learning motivations. Each hash URI below dereferences to this page; its fragment identifies the term. The reusable JSON-LD context is available as a separate static resource.

Motivations

learningObjective
States what a learner should be able to understand or do after engaging with the target.
coreClaim
States the central proposition conveyed by the target.
misconception
Identifies a likely but misleading interpretation of the target.
sourceRoute
Points an agent or learner toward evidence and related material for the target.
transition
Explains how the target connects to an adjacent part of the presentation narrative.

Use

Presentation annotations use these terms as TextualBody.purpose values. Standard Web Annotation motivations remain in use where they fit—for example, describing for an explanation and questioning for an optional check.
