# Authoring and computation route

Use this route for Quarto document syntax and metadata, citations, cross-references, figures, tables, callouts, includes, code cells, execution options, caching, parameters, and language engines.

## Lookup sequence

Search the live [Quarto LLM index](https://quarto.org/llms.txt) using the exact feature or error, then fetch the smallest matching page. Curated entry points:

- [Markdown Basics](https://quarto.org/docs/authoring/markdown-basics.llms.md) only for Quarto-specific authoring behavior
- [Front Matter](https://quarto.org/docs/authoring/front-matter.llms.md)
- [Cross References](https://quarto.org/docs/authoring/cross-references.llms.md)
- [Citations](https://quarto.org/docs/authoring/citations.llms.md)
- [Figures](https://quarto.org/docs/authoring/figures.llms.md)
- [Tables](https://quarto.org/docs/authoring/tables.llms.md)
- [Callout Blocks](https://quarto.org/docs/authoring/callouts.llms.md)
- [Execution Options](https://quarto.org/docs/computations/execution-options.llms.md)
- [Code Cells](https://quarto.org/docs/reference/cells/index.llms.md)
- [Caching](https://quarto.org/docs/computations/caching.llms.md)
- [Using Python](https://quarto.org/docs/computations/python.llms.md), [Using R](https://quarto.org/docs/computations/r.llms.md), or [Using Julia](https://quarto.org/docs/computations/julia.llms.md)

Use the relevant engine-specific page when cell syntax or execution semantics differ. Cite exact pages and distinguish Quarto behavior from Pandoc, Jupyter, Knitr, or language-runtime behavior. Generic Markdown questions without a Quarto-specific issue are outside this skill.
